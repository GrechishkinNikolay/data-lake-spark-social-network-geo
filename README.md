Проект реализует Data Lake и аналитические витрины для обработки событий социальной сети с геоданными. 
На основе координат пользовательских событий определяется ближайший город, рассчитываются пользовательские метрики, 
геоаналитика по зонам и витрина рекомендаций друзей с учётом общих каналов, истории переписок и расстояния между пользователями.

Данные обрабатываются в HDFS с использованием PySpark. Для расчёта витрин применяются оконные функции, работа с координатами,
временными зонами и агрегациями по пользователям, городам, неделям и месяцам. Обновление витрин автоматизировано через Airflow DAG.


Реализовано:
* структура Data Lake в HDFS для хранения исходных и аналитических данных;
* определение геопозиции событий по ближайшему городу на основе координат;
* пользовательская витрина с актуальным городом, домашним городом, историей перемещений и локальным временем;
* зональная витрина с недельными и месячными метриками сообщений, реакций, подписок и регистраций;
* витрина рекомендаций друзей на основе общих каналов, отсутствия переписки и расстояния до 1 км;
* автоматизация расчёта витрин через Airflow.


Структура Data Lake
Основные директории:
/user/master/data/geo/events/date=YYYY-MM-DD/    # Сырые события соцсети с координатами, Партиционирование по дате

Рабочие и аналитические:
/user/kolaygrech/data/
│
├── geo/                      # Локальные справочники геоданных
│   |── geo.csv               # Список городов Австралии
│   |── geo_with_timezone.csv # Список городов Австралии с таймзонами
│   └── events/               	# ODD: очищенные и обогащённые события (все типы)
│       └── date=YYYY-MM-DD/  	# партиционирование по дате
│
├── analytics/                # Data Sandbox: витрины для анализа
│   ├── user_activity/        # актуальный и домашний город, поездки
│   ├── geo_zones/            # статистика по городам
│   |── user_last_city/       # вспомогательная витрина с актуальным городом пользователя
│   |── events_closest_city/  # вспомогательная витрина событий(сообщений) с городом в котором оно произошло
│   |── events_geo_full/      # вспомогательная витрина - все события с актуальным городом
│   └── friend_recommend/     # рекомендации друзей
│
└── tmp/                    # временные данные

Обновление и форматы
Слой	                    	                Частота	    					                            Формат
/kolaygrech/data/geo/events/                    ежедневно                                                   Parquet
/kolaygrech/data/geo/	                        по мере обновления справочника	                            CSV
/kolaygrech/data/analytics/	                    ежедневно (через Airflow DAG)	                            Parquet
/kolaygrech/data/analytics/geo_zones/           для снижения нагрузки можно не жедневно, а еженедельно      Parquet
